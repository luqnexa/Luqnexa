# 「ぷろzyえくと」の変換修正

2026-10-11、ローマ字表に不足していた `zye` / `jye`（じぇ）、`sye`（しぇ）、`tye` / `cye`（ちぇ）を追加しました。これらの途中入力も既存の前方一致処理で保留されます。

共通コアは日本語と英字の境界で分けて解析するため、「zy」と「え」が別々に残っていました。末尾に2文字以上の未完の小文字ローマ字があり、直後が日本語の母音で、つなげた結果をローマ字表で最後まで解析できる場合だけ、両方を1音節として扱います。「ぷろzyえくと」「ぷろzyエクト」「purozyekuto」「purojyekuto」は「ぷろじぇくと」と読み、実辞書で「プロジェクト」が先頭候補になります。

認識済みの英単語、明示的な大文字は結合対象外です。`sexえ`、`ZYえ` は維持し、単独の `n` と日本語母音は従来どおり `nあ→んあ` になります。推測による全文の書き換えは行いません。

Rustテスト66件、fmt、clippy、releaseビルド、Rust 1.85のcore/parserテスト、128万エントリの実辞書での回帰テスト、Windows TSFホストテストが成功しました。文字ごとの入力とSpace変換も検証しています。新しい配布物は `C:/opencode-rust/target/windows-x64` に作成済みですが、稼働中IMEへのインストールは未適用です。
