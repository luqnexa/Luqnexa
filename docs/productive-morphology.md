# 基本形のメタデータから活用語形を生成する研究

2026-10-13。正解候補を生成できない文を順位学習だけで改善することはできません。既存辞書の動詞基本形と明示的な活用型から、否定・過去・丁寧・希望・接続等の語形をRustで生成するオフライン処理を追加しました。文章全体や固定評価の答えは登録しません。

自立動詞・基本形・対応済みの活用型・読みと表記の語尾一致を確認したエントリだけ扱います。一段、通常の五段、カ行促音便、ワ行ウ音便を区別します。特殊なユク型、ある・ござる、型の不明な語、文語、サ変・カ変等は推測しません。原形の読み・表記は変更せず、元エントリの品詞ID・コスト・重みを保持した派生タグを付けます。IDは原形のもので、新語形を実測した接続コストではありません。細かな接続は今後さらに検証が必要です。

24,137件の基本形エントリから362,055件の語形を生成しました。これは36万の独立した文章やニューラル学習例ではありません。重みも生成語形の実測頻度ではなく、元辞書から引き継いだ値です。全語形を独立した人間が点検したとは報告しません。

別NUDは10,547,446 bytes、インデックス符号列166,193 bytesです。クライアントは既存のブロック検索を使い、全語形をRAMに展開しません。二つの辞書を明示的に併用するSupplementedDictionaryを追加しました。単独・一括検索の一致、重複の整理、元辞書の保持をテストしています。Arc経由でも一括検索を委譲し、圧縮ブロックをまとめる処理を保ちます。
