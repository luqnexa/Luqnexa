# 30例の変換・補正とMeltype比較（2026-10-12）

ユーザー指定の入力と期待表記を `tests/sentence-suite.tsv` に保存した。読みどおりの変換19例、スペース処理4例、入力補正5例、意味を変える言い換え2例を含む。例5の「きかいにあった→機会に恵まれた」、例17の「問題は→問題を」は通常の読み変換とは区別する。

## 改善

技術名・外国語と日本語助詞の境界を処理する。Python/Rust/GitHub/Windows、program/repository/app、seoul/bonjour、CPU/GPUの指定表記を辞書と解析表に追加した。混在した韓国語は保持する。ローマ字内のスペースは変換時の代替読みとして扱い、既知の英単語だけの英文は結合しない。

必要な文・連語を辞書へ追加し、報告された誤変換24対を独自モデルの学習へ追加した。現在の合成学習38対・検証4対・保持テスト6対は全対で正例を優先した。重みは8,200バイト。今回の30例には専用の辞書と補正表があり、未知の文章への一般化を示す評価ではない。

補正はAIを有効にしてSpaceで変換した時の候補。Enterなしで確定せず、元のかな読みも候補に保持する。意味を変える2例では読みどおりの表記も残す。F9で無効にした場合は通常変換だけを行う。長すぎる入力は補正経路でも拒否する。

全体が辞書で検証済みの補正では、壊れた入力の全分割探索を省略し、候補と元の読みを直接保持する。一般の未知入力は通常の探索を継続する。

比較入力の空白除去は両製品に適用し、Luqnexaでは元の空白付き入力も別途検証した。期待値には補正・言い換え・特定の大文字小文字が含まれ、自然な別表記でも不一致と数える。今回の数値だけからMeltypeより一般的に高精度とは結論しない。通信方式は [MeltypeのTipServer](https://github.com/yksr-melt/Meltype/blob/main/src/Meltype/Tip/TipServer.cs) と [セッション応答形式](https://github.com/yksr-melt/Meltype/blob/main/src/Meltype.Core/Composition/MeltypeSession.cs) を確認した。
