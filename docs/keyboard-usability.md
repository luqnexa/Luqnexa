# キーボード操作の改善

2026-10-13。Luqnexaの予定学習・青空文庫監視を削除しました。旧教材は保持し、Qwenや自動学習は起動しません。

WindowsではF6で全角、Shift+F6で半角、Shift+F10で全角にします。変換候補を選択中ならその候補、未選択なら元入力へ適用します。英字・数字・ASCII記号・空白・カタカナを扱い、濁音・半濁音の復元に対応します。日本語・韓国語・絵文字は保持します。F10は従来通り元の英字列、F12/JIS半角全角キーは日英切り替えです。表記変更は自動確定せずEnterで確定します。設定画面への入口をダッシュボードに追加しました。OSの選択を無断で変更しません。

打鍵ミス候補は隣接キー・入れ替え・余分な一文字・QWERTY配列全体の左右ずれを扱います。`jr;;p`から`hello`の候補を作れます。4～24 bytesの小文字入力に限定し、辞書で確認した英語候補だけ採用し、元入力も保持します。Shiftによる大文字入力は補正対象外です。日本語の全文章や複数の異なる誤りを完全に修正する機能ではありません。

iOSにRust Sessionを使うQWERTYキーボード拡張を追加しました。ローマ字日本語・英字・数字、Shift、変換候補、全角半角、取消、削除、明示確定、🌐切り替えを扱います。候補タップはユーザーの確定操作です。アプリ内にOS設定を開くボタンを追加しました。初回は「設定 → 一般 → キーボード → キーボード → 新しいキーボードを追加」でLuqnexaを追加してください。

`RequestsOpenAccess=false`で、ネットワーク・入力履歴取得・背景学習は実装しません。新Rustニューラルモデルは測定アプリに残し、キーボードは既存の共通変換と同梱の小規模辞書を使います。フル辞書搭載、新モデルのIME統合、フリック入力、Android UIは今後の対応です。iOSの安全な入力欄はOSキーボードへ切り替わります。

Meltype・Simejiとの同条件実測は未実施です。完全補正、90%精度、5ms、競合を上回る性能は達成と報告しません。青空文庫の読み込みでは、今回のキー操作・UI・IME接続の不具合は直せないため追加取得は行いません。

参考：[Appleのキーボード拡張](https://developer.apple.com/library/archive/documentation/General/Conceptual/ExtensibilityPG/CustomKeyboard.html)、[Windows設定URI](https://learn.microsoft.com/en-us/windows/apps/develop/launch/launch-settings)。
