# Qwenを教師にした独自AIの学習

2026-10-12に、保存済みのQwen3-4B-Q4_K_Mを端末内で動かし、独自の候補ランキングモデルを追加学習した。Qwen自体の重みを更新するファインチューニングではなく、教師の候補選択を小型モデルに学習させるハードラベル蒸留である。文章生成モデルへの置き換えではない。

教師モデルは[Qwen公式のGGUF](https://huggingface.co/Qwen/Qwen3-4B-GGUF)（Apache-2.0）。取得済みモデルのSHA-256を確認してから、専用の認証付きループバックサーバーを起動する。IMEの設定・起動登録・個人履歴・現在入力中の文章は読み書きしない。HTTPプロキシは無効化し、終了時にはこの学習処理が起動したサーバーだけを停止する。

## 学習と評価

`models/qwen-teacher-pairs.jsonl` に新たに作成した候補ペアを記録した。橋・箸・端、機械・機会、AI・愛、雨・飴、大文字小文字などが対象。正解候補は事前に作成した参照表記であり、人間による第三者評価ではない。

20組の学習候補をQwenに提示し、候補の順番を入れ替えてもう一度判定する。両方の判定が参照表記に一致した例だけを採用する。Qwenが出した文をそのまま正解として採用する方式ではない。初回の英語指示では6組しか採用できず、日本語の指示と番号付き候補へ修正した再実行で16組を採用、4組を除外した。

既存の38組と採用した16組を学習に使用。既存の検証4組でエポックを選択した。既存テスト6組と新しいテスト8組は重みの更新に使用しない。前回の50問の入力・結果も学習に使用していない。ただし新しいテストは同じ語彙分野の類似文であり、完全に独立した実利用評価ではない。二回の試行で同じテスト集合を評価したため、初見の最終評価セットとも扱わない。

| 重みだけで二候補を比較する評価 | 学習前 | 学習後 |
| --- | ---: | ---: |
| 新しい未学習の8組 | 5/8 | 7/8 |
| 既存テスト6組 | 6/6 | 6/6 |
| 検証4組 | 4/4 | 4/4 |
| 今回学習した16組 | 9/16 | 16/16 |

これは候補ペアの比較結果であり、入力解析・候補生成・辞書頻度を含むIME全体の精度ではない。現在のIMEは、学習済みの全文表現に一致する範囲にしかこのモデルを適用しない。**その適用範囲の制限も含めると、新しいテスト8組では学習前後ともモデルによる優劣がつかず8組すべて同点だった。** したがって7/8を現在のIMEの変換成功率として報告できない。未知文でも効果を出す適用範囲の設計と、変換全体の回帰試験が必要になる。

学習後モデルは8,200バイト、SHA-256は `22d1b82abdab5d20b1b2a522ee0a26b050ca48f012e8e812ea4e3deab9b5bd52`。学習・推論・検証を含む再実行は111.62秒だった。IMEの変換速度は今回測定しておらず、高速化を達成したとは判断しない。

モデルは `.cache/qwen-distillation-v2/` に保存し、稼働中IMEにも標準の `models/native-model.bin` にも適用していない。全件成功・全般的な文章理解の完成とは扱わない。

## 再実行

```powershell
python scripts/distill-qwen.py --output .cache/qwen-distillation-next
python scripts/distill-qwen.py --verify --output .cache/qwen-distillation-v2
python scripts/test-distill-qwen.py
```

学習には `scripts/setup-local-ai.py` で準備済みのモデルとランタイムが必要。`--verify` はQwenを起動せず、採用判定・学習データ・エポック・重みの再現性・SHA-256・適用表現を確認する。教師の推論結果を再生成した場合は、実行環境によって同じ結果になる保証はない。

実測記録は [評価JSON](../benchmarks/results/qwen-distillation-v2.json)、[教師の採否記録](../benchmarks/results/qwen-teacher-audit-v2.json)。ネットワーク不要のテストをGitHub Actionsへ追加した。GitHub上での実行は未確認。

## 継続学習

その後、ユーザーの指示により[アプリ起動中の常駐学習](app-learning.md)へ変更した。以下の毎時方式は履歴であり、現在の `luqnexa-qwen` は監視専用。

2026-10-12に、このチャットへ戻る1時間ごとの継続学習を登録した。名前は「LuqnexaのQwen継続学習」、IDは `luqnexa-qwen`。各回で最大8組の合成候補ペアを追加し、教師判定・独自モデル学習・再現性検証・固定評価を実行する。個人の入力履歴や他アプリの文章は取り込まない。通常の実行では通知せず、意味ある改善・停止・失敗・判断が必要な場合に通知する。

データは `.cache/qwen-continuous/pairs.jsonl`、各回の固定スナップショットと成果物は `.cache/qwen-continuous/runs/`、最新結果は `.cache/qwen-continuous/latest.json` に保持する。`--teacher-cache` によって、文脈・候補・教師モデルのSHA-256・プロンプトが同じ場合だけ過去の教師判定を再利用する。入力順に偏った判定はキャッシュしても採用しない。

初回は8組を新規追加し、6組を採用、2組を除外した。既存判定20組を再利用し、合計28組中22組が教師の検査を通った。学習と評価は55.58秒、テスト7件と成果物の再現性・SHA-256確認に成功した。未学習8組の重み比較は7/8を維持、適用範囲を含めると8組とも同点で、未知文への効果は依然未確認。モデルは検証用として保存し、IMEには適用していない。[初回結果](../benchmarks/results/qwen-continuous-initial.json)を参照。

データが500組を超えた場合は、全件再学習を続ける前に処理量を抑える方式を検討する設定にした。この定期実行はCPUを常時占有する無限ループではない。ローカルの定期実行にはPCとデスクトップアプリが起動している必要がある。[公式の定期実行ドキュメント](https://learn.chatgpt.com/docs/automations?surface=app)を参照。
