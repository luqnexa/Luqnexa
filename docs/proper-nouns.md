# 固有名詞とAI表記の修正

後続の指定で「あい」単体もAIを第一候補に変更しました。文脈モデルの最新実装と確認結果は [端末内の文章理解AI](local-llm.md) を参照してください。以下は各修正段階の記録です。

2026-10-11: 自作の `dictionaries/proper-nouns.tsv` に170エントリを追加。英語の製品・サービス・技術名、日本語の読み、企業名・地名・姓・作家名の初期リストです。すべての固有名詞を網羅した辞書ではありません。重みは調整用の値で、実測頻度ではありません。

`ChatGPT`、`chatgpt` など登録済みの英語名は入力した大文字・小文字を維持します。`ChatGPTde`、`GitHubwo` のようなローマ字助詞付き入力にも対応します。日本語読み `ちゃっとじーぴーてぃー` と混在入力 `ちゃtgpt` は変換操作で `ChatGPT` の候補になります。未登録の英語とローマ字の区別は依然として曖昧で、全入力を英語として保存する機能ではありません。

ユーザーの明示的な指定に合わせて `あいによる`、`あいによって`、`あいにより` に `AI` 表記の候補を登録しました。`あい` 単体から長い文章や `AI` を自動挿入する変更はしていません。`あいによる` の第一候補は `AIによる` ですが、「愛による」など別の意図もあり得るため、この限定的な登録が全文の意味理解を実現するわけではありません。

新規語は圧縮辞書の上に読み取り専用の辞書として重ねます。既存 `.nud` の再構築は不要です。元辞書の検索エラーは引き続き呼び出し元へ返します。入力やテスト文章は外部AIに送信しません。

確認方法:

```powershell
cargo test --workspace
cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
./scripts/build-windows.ps1
./scripts/test-context-ai.ps1 -DictionaryPath C:/opencode-rust/target/windows-x64/base.nud
./scripts/test-windows.ps1 -SkipBuild
```

AI有効・無効の両方で、一文字ずつ入力した固有名詞、助詞との接続、確定前の自動挿入がないことを回帰テストします。「AIによるテスト」は既存のローカル候補ランキングを有効にしたテストであり、外部LLMによる独立評価や一般的な変換精度の証明ではありません。実アプリへの物理キーの到達・候補描画はTSFホストテストの測定範囲外です。

今回の確認結果: Rustテスト68件成功・100万回の監査テスト1件は通常実行では除外。fmt、Clippy、release build成功。追加170エントリの完全な読みを1,285,626エントリのNUDで変換した結果は170/170成功。期待値・実際の第一候補・実行ファイルと辞書のSHA-256は `benchmarks/results/proper-nouns-audit.json` に保存しました。これは既知語の回帰結果で、未知語の精度評価ではありません。日英混在入力と文脈・個人学習の実辞書テストも成功しました。

Windows TSFホスト: 100回ウォームアップ後1000回、8イベントのp50 1.2271ms / p95 2.1703ms / 最大3.4172ms。描画・登録処理を含まず、このWindows端末の値です。iPhone SE第2世代での要件達成を示すものではありません。

追加修正: 「あいをつかい」を「AIを使い」にする依頼に合わせ、使用・利用の表現20エントリを追加しました。初期170件と合わせ190件です。「あいをつかう」「あいをつかって」「あいをつかいたい」「あいをつかいます」、すでに漢字を含む「あいを使い」に対応します。語の完全な読みと文章中の接続を確認し、AI有効・無効、一文字ずつの入力、未確定状態を検証します。「あい」「あいを」「あいをつたえる」「あいする」「あいをこめて」をAIへ変更しない回帰テストも追加しました。限られた使用表現への辞書対応であり、すべての文章でAIと愛を意味から判別できるものではありません。

追加20件のNUD変換は20/20成功し、結果を `benchmarks/results/ai-use-audit.json` に保存しました。「あいをつかって文章を書く」「あいをつかいたいです」「あいをつかいます。」「あいをりようする」の文章内変換と、元の文脈・個人学習・英語名の回帰テストも成功しました。
