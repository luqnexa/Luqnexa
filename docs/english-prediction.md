# 日英入力・予測候補の更新

この文書は492エントリ版の履歴です。後続の日本語辞書約128万エントリへの拡充と検索上限の変更は [日本語辞書増量報告](japanese-dictionary.md) を参照してください。

2026-10-11。ユーザーからの英字・ネットスラング入力の不具合報告に対応しました。旧版はすべての英字をローマ字として解釈し、数字や多くの記号をcompositionに追加できませんでした。

## 操作

- `omg`、`lol`、`gg`、`www`等の登録済み英語/スラングは原文で確定できます。大文字表記も保持します。
- F10→Enterで未登録の英字列もそのまま確定できます。
- F12で英字モードへ切り替えると、英語文章・URL・新しい略語をそのまま入力できます。Spaceで単語と空白を確定します。F12で日本語に戻ります。
- 入力中に前方一致予測を表示します。上下キーで選びEnterで確定します。未選択の予測を自動確定しません。
- Windows候補上限を8→24件にし、8件ずつページ表示します。数字・Shift/Caps Lock・記号はOSのキーボードレイアウトで解釈します。

日本語モードの短い`no`等は引き続きローマ字として解釈します。登録済みの英単語との曖昧性は残るため、確実な英語入力は英字モードを使用してください。スペル修正・次単語予測・文章生成・会話学習は追加していません。

## 辞書と実装

同梱辞書は62→492エントリです。元の62語に手作業の日本語210行、英語/スラング234行を加え、同一読み・表記・品詞を重複排除しました。件数は品詞別エントリで、ユニーク単語数ではありません。頻度は説明用の重みです。完全な日本語/英語辞書や、機械学習で訓練したモデルではありません。入力内容の収集・送信は追加していません。

追加データは`dictionaries/extended-ja.tsv`、`english.tsv`。共通処理は`nextime-core`のSession/Engine、前方一致は`nextime-dict`・`nexc-lite`、ABIは`nextime-ffi`、Windowsの文字解釈・候補表示は`platforms/windows/src`を変更しました。

前方一致は索引から開始し、RAM辞書は最大2048行、NUDは最大8ブロック、個人追記辞書は最大2048行を調べます。非常に広い接頭辞では辞書全体の最頻候補を保証しません。空入力の全辞書走査は行いません。専用の頻度付き予測索引は今後の課題です。
