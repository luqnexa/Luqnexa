# 日本語・英語混在文の1,000例学習

2026-10-13にユーザーの依頼で、訓練専用の合成問題1,000例を作成して学習した。

教材は `models/chatgpt-training/mixed-20261013-1000.jsonl`。閲覧用は同名の `.tsv`、生成手順は `build-mixed-1000.py`。固有名詞のケース、指定変数のケース、英単語の保持、正式略称のケースを各250例とした。各分野25語を、点検した文型へ組み合わせた。採用した文型は41種類であり、1,000種類の独立した意味・文脈ではない。

入力と正答表記は各1,000件すべて異なり、既存の訓練・固定評価入力と重ならない。全件の語彙・文型との対応を検査し、用意した44文型のローマ字から日本語への読みをCLIで照合した。点検中に「運用」の `n` と `y` の境界を `n'` に修正してから訓練した。混在する英語の前半を含む実IME全体の変換テストとは異なる。合成教材の点検は独立した人間の正解確認ではない。
