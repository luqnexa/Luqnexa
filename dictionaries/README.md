# NextIME 辞書

`extended-ja.tsv`、`english.tsv`、`phrases-ja.tsv`も自作データです。組み込み辞書はこれらと`sample-ja.tsv`を結合した639エントリです。`phrases-ja.tsv`は長い連絡表現134件を含みます。

`mozc-ja.tsv`はMozc公式公開辞書から取得したデータと自作辞書を結合したWindows用の大規模データです。取得元の各条件を保持し、全体をAGPLとして扱いません。元のライセンス・著作権・免責表示は [MOZC-NOTICES.txt](MOZC-NOTICES.txt)、固定リビジョンと取得ファイルのSHA-256は [mozc-source.json](mozc-source.json) にあります。再取得・ビルド方法と実測値は [日本語辞書増量報告](../docs/japanese-dictionary.md) を参照してください。

`sample-ja.tsv` は本プロジェクトで作成した62エントリのデモデータです。ライセンスはAGPL-3.0-onlyです。既存IMEや辞書から抽出していません。読み・表記・品詞・説明用頻度を保存します。多言語辞書や網羅的な日本語辞書ではありません。

UTF-8、1行1エントリ、タブ区切りで4フィールドを指定します。

```text
はし	橋	noun	8000
はし	箸	noun	7000
```

空行と行頭 `#` のコメントを無視します。読みは検索に使用する正規化済み表記（通常ひらがな）で登録してください。辞書ローダーはローマ字・カタカナの自動正規化をしません。頻度は0〜4294967295の整数です。品詞は現在の候補スコアでは使用しませんが、読み込み時に保持します。

読み・表記・品詞は空文字と制御文字を禁止します。上限は読み128文字、表記256文字、品詞64 UTF-8バイトです。不正な行は行番号と理由を返し、辞書全体の読み込みを失敗させます。同じ「読み・表記・品詞」の重複は最大頻度を保持します。異なる品詞は別エントリとして保持します。

TSV辞書とMaxの構築工程では全エントリをRAMに読み込みます。Phase 2の `.nud` はディスク上の圧縮辞書を索引・ブロックキャッシュで検索し、全辞書のRAM展開を不要にします。ただし1億エントリや1GiB以下の達成は未検証です。[NEXC仕様](../docs/nexc-format.md) を参照してください。
